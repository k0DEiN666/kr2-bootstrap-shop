# TechnoPoint — интернет-магазин электроники

## Контрольная работа №2
Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание проекта
Учебный интернет-магазин электроники с главной страницей, каталогом товаров,
страницей отдельного товара и формой оформления заказа. Вёрстка построена
на Bootstrap 5.

## Используемый фреймворк
Bootstrap 5.3.8

## Способ подключения
Bootstrap подключён через CDN:

```html
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css" rel="stylesheet">
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.bundle.min.js"></script>
```

# Реализованные компоненты Bootstrap

navbar — навигация на всех страницах с адаптивным мобильным меню
card — карточки товаров
btn — кнопки действий (разные варианты: primary, outline, secondary)
badge — метки «Хит», «Новинка», «Скидка»
alert — информационные сообщения
modal — быстрый заказ и подтверждение отправки формы
form-control, form-select, input-group, form-check — форма заказа
accordion — описание/характеристики товара
carousel — баннер с акциями на главной
nav-tabs / tab-content — доставка/оплата на странице заказа
pagination — постраничная навигация каталога
breadcrumb — навигационная цепочка на странице товара
